Climate Color: Core Reference

This page shows the one true copy of the color system. Every value here is read live from the files in core/, so if this page looks right, the source is right. Nothing on this page is typed in by hand.

Colors bring people in; archetypes make people understand, and stay.

The six colors

In list order, starting at Red. Words in a brand color on white use its darker text shade, which must reach at least 4.5 to 1. Pill words use the text shade mixed 88% with black, on an 8% tint of the color. The label is the black or white text to use on the full brand color. The light tints are three hand-picked shades of each color, lightest first.

Accessibility checks

Every page reads its colors and words from core/. These checks confirm the labels on each brand color and each color's text shade stay readable (at least 4.5 to 1), so a palette change can't quietly break it.
